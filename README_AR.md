# مكسب Pay — مشروع أندرويد تجريبي

## ماذا يعمل الآن؟
- واجهة عربية من اليمين إلى اليسار.
- رصيد تجريبي محفوظ محليًا على الجهاز.
- استقبال تجريبي يضيف مبلغًا وهميًا بعد تأكيد المستخدم.
- تحويل تجريبي يخصم من الرصيد الوهمي ويتطلب رقم مستلم ومبلغًا صحيحًا.
- سجل عمليات محفوظ محليًا.
- زر لإعادة ضبط بيانات التجربة.
- لا يتصل التطبيق ببنك أو محفظة أو مقدم دفع، ولا ينقل أموالًا حقيقية.

## بناء التطبيق
1. فك ضغط الملف.
2. افتح Android Studio على كمبيوتر.
3. اختر Open وحدد مجلد `MaksabPay_Android_Project`.
4. انتظر مزامنة Gradle وتنزيل Android SDK عند الحاجة.
5. من قائمة Build اختر Build APK(s).

**ملاحظة:** لا يوجد ملف APK جاهز في هذا الأرشيف؛ هذه ملفات المصدر. لم يتم بناء المشروع أو اختباره على جهاز في بيئة الإنشاء الحالية.

## قبل أي إطلاق مالي حقيقي
- يجب التعاقد مع مقدم خدمات دفع مرخّص ومصرّح له بتقديم الخدمة المقصودة.
- يجب أن يراجع مقدم الدفع نشاطك ويمنحك بيانات التكامل الرسمية وبيئة اختبار.
- غالبًا ستحتاج إلى خادم خلفي آمن؛ لا تضع مفاتيح سرية في تطبيق الهاتف ولا تثق في الرصيد المحلي.
- يجب أن تتم مراجعة متطلبات الترخيص والامتثال وحماية البيانات ومكافحة الاحتيال والتسوية المالية في مصر.
- إذا كان صاحب المشروع دون 18 عامًا، فاستعن بولي أمر بالغ وبجهة قانونية/تجارية مؤهلة لتحديد ما يمكن تسجيله والتعاقد عليه وفق الشروط.
- لا تطلب من المستخدمين إرسال أموال أو بيانات بطاقة إلى النسخة التجريبية.

## أمان وخصوصية
النسخة التجريبية لا تطلب بريدًا إلكترونيًا أو كلمة مرور أو رقم هوية أو بيانات بطاقة. بيانات التجربة محفوظة محليًا فقط ويمكن مسحها من داخل التطبيق.

## بناء APK عبر GitHub Actions (بدون تثبيت Android Studio)
أضفنا ملف workflow ليبني APK تلقائيًا على خوادم GitHub، لكن يلزم رفع المشروع إلى مستودع GitHub وتشغيل Actions:
1. فك ضغط المشروع.
2. أنشئ مستودعًا جديدًا في GitHub من حسابك، ثم ارفع محتويات المجلد إليه مع المجلد المخفي `.github`.
3. افتح تبويب Actions في المستودع، وشغّل **Build Maksab Pay APK** إذا لم يبدأ تلقائيًا.
4. افتح نتيجة التشغيل الناجح، ومن قسم Artifacts نزّل `MaksabPay-debug-APK`.
5. فك ضغط ملف Artifact ثم افتح `app-debug.apk` على جهاز Android للتثبيت، إذا سمحت إعدادات الجهاز بذلك.

إذا كنت لا تريد استخدام GitHub، فافتح المشروع في Android Studio على كمبيوتر واختر Build > Build APK(s).
تنبيه: هذه طريقة بناء آلية وليست ضمانًا أن البناء سينجح دون تعديلات؛ يجب مراجعة أي خطأ يظهر في سجل البناء. APK التجريبي لا ينقل أموالًا حقيقية.
